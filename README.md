# daily_exchange_rate
## 📝 App အကြောင်း မိတ်ဆက်
This Flutter project will be able to watch international daily exchange rate for myanmar kyat.<br>
မြန်မာကျပ်ငွေရဲ့နိုင်ငံတကာငွေလဲနှုန်းတွေကိုကြည့်ရှုနိုင်တဲ့applicationဖြစ်ပါတယ်။<br>
UI ပိုင်းကို သပ်ရပ်ပြီးမျက်စိပသာဒဖြစ်အောင် ပြုလုပ်ထားသလို အမှောင်မုဒ် (Dark Mode) လည်းပါဝင်ပါတယ်။ <br>
> (it is only for pracitce, not actual rate😆)<br>


ဒီ Project ကို Flutter (Riverpod State Management) သုံးပြီး အကောင်းဆုံး တည်ဆောက်ထားပါတယ်။

### အောက်ပါ Package🧰 တွေကိုအသုံးပြုထားပါတယ် - 
  go_router<br>
  flutter_riverpod<br>
  dio<br>
  shared_preferences<br>
  intl<br>
  flutter_screenutil<br>
  freezed_annotation<br>
  json_annotation<br>
> ⚙️ **Dev_dependencies**<br>
  flutter_launcher_icons<br>
  freezed<br>
  json_serializable<br>
  build_runner<br>

I use api of this link **https://forex.cbm.gov.mm/api**
